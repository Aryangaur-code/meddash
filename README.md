# AI Medical Co-Pilot

The AI Medical Co-Pilot is a clinical assistant application designed to reduce the administrative burden on physicians while significantly enhancing diagnostic accuracy. Operating as an ambient background tool during consultations, it processes natural language and leverages a Knowledge Graph-driven architecture. This advanced approach allows the system to map complex relationships between a patient's current symptoms, lab results, and historical context against established medical ontologies. Consequently, the Co-Pilot can automatically generate structured clinical notes, perform deep report analysis, predict potential diseases, and flag severe risks with a high degree of explainability and precision.

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app).
